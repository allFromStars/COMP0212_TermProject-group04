# COMP0212_TermProject-group04

Group research and implementation for the COMP0212 term project.

## Caffeine feasibility pilot

The current exploratory work is in [research/caffeine-pilot](research/caffeine-pilot/README.md).
It includes the [research design](research/caffeine-pilot/Research%20Design.md),
source-derived inputs, MATLAB code, and selected reference results.

To run it, open `research/caffeine-pilot` in MATLAB and run:

```matlab
run_caffeine_pilot
```

Base MATLAB is sufficient; no extra toolboxes, Python installation, or downloads
are needed for this run. The pilot was verified with MATLAB R2025b.

The inputs are approximate digitized group means and published summaries, not
individual participant records. An unresolved external clearance discrepancy is
documented in the design and included results. The timing scenarios are exploratory
and do not establish individual risk or sleep effects.
